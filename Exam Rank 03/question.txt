Problem 1: Bracket Validator
Write a function that validates if brackets are properly matched.
Valid brackets: (), [], {}
Other characters are ignored

Return True if valid, False otherwise
Examples:
"()" → True
"()[]{}" → True
"{[]}" → True
"([)]" → False
"(((" → False
"abc(def)ghi" → True (non-brackets ignored)

Problem 2: Echo Validate (Palindrome)
Write a function that checks if a string is a palindrome.
Ignore spaces and case

Return True if palindrome, False otherwise
Examples:
"racecar" → True
"A man a plan a canal Panama" → True (ignoring spaces and case)
"hello" → False

Problem 3: Pattern Tracker
Write a function that counts consecutive number pairs in a string where the second digit is 1 greater than the first (0-9).
Examples:
"abc123def" → 2 (pairs: "12" and "23")
"456789" → 4 (pairs: "45", "56", "67", "78")
"abc987def" → 1 (pair: "87")
"135" → 0 (no consecutive pairs)

Problem 4: Shadow Merge
Write a function that merges two sorted lists into one sorted list.
Examples:
[1, 3, 5], [2, 4, 6] → [1, 2, 3, 4, 5, 6]
[1, 2, 3], [4, 5, 6] → [1, 2, 3, 4, 5, 6]
[], [1, 2] → [1, 2]

Problem 5: Twist Sequence (Rotate Array)
Write a function that rotates an array to the right by k positions.

Last k elements move to the front
Examples:
[1, 2, 3, 4, 5], k=2 → [4, 5, 1, 2, 3]
[1, 2, 3, 4, 5], k=3 → [3, 4, 5, 1, 2]
[1, 2], k=1 → [2, 1]

Problem 6: Whisper Cipher (Caesar Cipher)
Write a function that shifts alphabetical characters by a given amount.

Only shift letters (a-z, A-Z)
Preserve case
Other characters remain unchanged
Wraparound: 'z' + 1 = 'a'
Examples:
"hello", shift=3 → "khoor"
"hello world!", shift=3 → "khoor zruog!"
"xyz", shift=3 → "abc"
"ABC", shift=1 → "BCD"

Problem 7: String Sculptor
Write a function that alternates character cases.

1st alphabetical character: lowercase
2nd alphabetical character: uppercase
3rd alphabetical character: lowercase
Continue alternating...
Non-alphabetical characters are unchanged but don't affect the alternation count
Examples:
"hello" → "hElLo"
"abc" → "aBc"
"a1b2c3" → "a1B2c3"

Problem 8: Cryptic Sort
Write a function that sorts a list of strings according to multiple criteria:

Primary sort: Length (shortest first)
Secondary sort: Alphabetically (if same length)
Tertiary sort: Number of vowels (fewest first, if still tied)
Requirements:

Handle empty strings and lists
Treat mixed case as lowercase for comparison
Ignore special characters when counting vowels
Vowels are: a, e, i, o, u
Examples:
["apple", "pie", "a"] → ["a", "pie", "apple"]
  (lengths: 1, 3, 5)

["dog", "cat", "bee"] → ["bee", "cat", "dog"]
  (same length 3, alphabetically: bee < cat < dog)

["aaa", "eee", "bbb"] → ["bbb", "aaa", "eee"]
  (same length 3, alphabetically same group, vowel counts: 0, 3, 3)

Problem 9: String Permutation Checker
Write a function that checks if two strings are permutations of each other.

A permutation means same characters, possibly rearranged
Examples:
"abc", "bca" → True
"abc", "def" → False
"aab", "aba" → True

Problem 10: Number Base Conversion
Write a function to convert numbers between different bases.

Support common bases: binary (2), octal (8), decimal (10), hexadecimal (16)
Input: number as string, source base, target base
Output: converted number as string
Examples:
"1010", base_from=2, base_to=10 → "10"
"FF", base_from=16, base_to=10 → "255"
"10", base_from=10, base_to=2 → "1010"

Problem 11: Find the Difference
You are given two strings s and t. String t is generated by randomly shuffling string s and then adding one more letter at a random position. Return the letter that was added to t.
Examples:
s = "abcd", t = "abcde" → "e"
s = "", t = "y" → "y"
s = "a", t = "aa" → "a"

Problem 12: Find Index of First Occurrence
Given two strings needle and haystack, return the index of the first occurrence of needle in haystack, or -1 if needle is not part of haystack.
Examples:
haystack = "sadbutsad", needle = "sad" → 0
haystack = "leetcode", needle = "leeto" → -1
haystack = "hello", needle = "ll" → 2

Problem 13: Valid Anagram
Given two strings s and t, return true if t is an anagram of s, and false otherwise.
Examples:
s = "anagram", t = "nagaram" → True
s = "rat", t = "car" → False
s = "listen", t = "silent" → True

Problem 14: Move Zeroes
Given an integer array nums, move all 0's to the end while maintaining the relative order of the non-zero elements. Note: You must do this in-place without making a copy of the array.
Examples:
[0, 1, 0, 3, 12] → [1, 3, 12, 0, 0]
[0] → [0]
[1, 2, 3] → [1, 2, 3]

Problem 15: Plus One
You are given a large integer represented as an integer array digits, where each digits[i] is the ith digit of the integer. The digits are ordered from most significant to least significant. Increment the large integer by one and return the resulting array of digits.
Examples:
[1, 2, 3] → [1, 2, 4]
[4, 3, 2, 1] → [4, 3, 2, 2]
[9] → [1, 0]
[9, 9, 9] → [1, 0, 0, 0]

Problem 16: Sign of the Product of an Array
Implement a function signFunc(x) that returns:

1 if x is positive
-1 if x is negative
0 if x is equal to 0
You are given an integer array nums. Let product be the product of all values in the array. Return signFunc(product).
Examples:
[-1, -2, -3, -4, 3, 2, 1] → 1
[1, 5, 0, 2, -3] → 0
[-1, 1, -1, 1, -1] → -1

Problem 17: Can Make Arithmetic Progression
A sequence of numbers is called an arithmetic progression if the difference between any two consecutive elements is the same. Given an array of numbers arr, return true if the array can be rearranged to form an arithmetic progression. Otherwise, return false.
Examples:
[3, 5, 1] → True (can be rearranged to [1, 3, 5] with difference 2)
[1, 2, 4] → False
[1, 3, 5, 7] → True (difference is 2)

Problem 18: Monotonic Array
An array is monotonic if it is either monotone increasing or monotone decreasing.
An array nums is monotone increasing if for all i <= j, nums[i] <= nums[j]

An array nums is monotone decreasing if for all i <= j, nums[i] >= nums[j]
Given an integer array nums, return true if the array is monotonic, or false otherwise.
Examples:
[1, 2, 2, 3] → True (increasing)
[6, 5, 4, 4] → True (decreasing)
[1, 3, 2] → False (neither)
[3, 3, 3, 3] → True (both increasing and decreasing)

Problem 19: Repeated Substring Pattern
Given a string s, check if it can be constructed by taking a substring of it and appending multiple copies of the substring together.
Examples:
"abab" → True (substring "ab" repeated twice)
"aba" → False
"abcabcabcabc" → True (substring "abc" repeated 4 times)
"aaa" → True (substring "a" repeated 3 times)[12:32 PM]
